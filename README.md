# Megathon X: Singularity
## Project GreenProof

### Setup Instructions
1. Run `pip install -r requirements.txt` (or use your preferred package manager).
2. Follow ingestion processes in `ingest/`.

### Run Instructions
1. Execute `python greenproof/generator/run.py` to generate the synthetic data.
2. Ensure you have the `.agent` state and `readmes/` reference docs handy.
